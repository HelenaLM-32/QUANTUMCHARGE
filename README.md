# Quantum Charge

Concepto de marca y experiencia web para una colección ficticia de bebidas
energéticas. El proyecto reúne dirección visual, diseño de packaging y una
landing page responsive desarrollada con Astro.

Incluye una landing de marca y una página de proceso creativo con el sistema
visual, la colección de envases y la experiencia digital.

## Vista previa local

```sh
npm ci
npm run dev
```

Astro iniciará el sitio en `http://localhost:4321`.

## Producción

```sh
npm run build
npm run preview
```

La compilación estática se genera en `dist/`.

## Tecnologías

- Astro
- HTML y CSS
- Recursos visuales propios del concepto

## Alcance

Quantum Charge es un proyecto conceptual de portfolio. Los productos, la marca
y el contenido promocional son ficticios; la web no procesa compras ni
suscripciones.
